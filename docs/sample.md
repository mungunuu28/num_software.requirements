# Системийн шаардлагууд (SRS Sample)
## 1. Функциональ шаардлага
- Хэрэглэгч нэвтрэхдээ цахим шуудан болон нууц үгээ оруулна.
- Систем нь нууц үг сэргээх 6 оронтой кодыг хэрэглэгчийн имэйл рүү илгээнэ.
## 2. Функциональ бус шаардлага
- Систем маш хурдан ажиллах ёстой.
- Вэб хуудас нь хэрэглэгчдэд ээлтэй байна.
- The API response must be fast and easy to integrate.
